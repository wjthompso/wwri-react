Drop the two new source hero videos here, then run from repo root:

  bash scripts/encode-home-hero-videos.sh

Expected filenames (any name works if you pass paths to the script):
  14698206_3840_2160_24fps.mp4  →  home-hero-1.mp4
  13654867_3840_2160_30fps.mp4  →  home-hero-2.mp4

Each output is trimmed to 30s max, scaled to 1920×1080, H.264, no audio, web-optimized.
